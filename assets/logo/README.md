# PSYKL Logo Asset Pack

This package was generated from the approved PSYKL logo concept.

## Source

- `source/psykl-icon.svg` — vectorized icon mark, transparent background.
- `source/psykl-icon-transparent-2048.png` — high-resolution transparent icon.
- `source/psykl-icon-ios-master-2048.png` — opaque white-background production master.
- `source/psykl-wordmark.svg` / `.png` — standalone PSYKL wordmark.
- `source/psykl-lockup.svg` / `.png` — combined mark + wordmark.

## Web

- `favicon.ico` — multi-resolution favicon.
- `favicon-16x16.png`, `favicon-32x32.png`, `favicon-48x48.png`
- `apple-touch-icon.png` — 180×180.
- `android-chrome-192x192.png`, `android-chrome-512x512.png`
- `maskable-192x192.png`, `maskable-512x512.png`
- `site.webmanifest`
- `safari-pinned-tab.svg`
- Additional transparent icon PNGs from 16×16 through 1024×1024.

## iOS

- `ios/AppIcon.appiconset/` — Xcode-compatible icon set with `Contents.json`.
- Includes iPhone, iPad, and 1024×1024 App Store marketing sizes.
- iOS production icons are opaque (white background) and do **not** contain the visualization guide border. iOS applies its own app-icon mask.

## Preview

- `previews/ios-icon-preview-with-guide-border.png`
- `previews/psykl-ios-preview.svg`

The light rounded-square border is provided only as a visualization preview, not as part of the production iOS icon.
