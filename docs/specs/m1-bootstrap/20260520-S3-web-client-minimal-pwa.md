# M1 Spec 3: web_client minimal PWA — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a minimal installable PWA that lets a user type a task title, click create, and see the new task appear in a list, exercising the full architecture (PWA → service-task API → pglite → back).

**Architecture:** Vite + React (SPA mode) with `vite-plugin-pwa` for the Web App Manifest. State is local React state (no Redux/Zustand/TanStack Query in M1 — M2 adds an offline-first store). HTTP calls go through `openapi-fetch` typed against `components/service-task/openapi.json` via `openapi-typescript`-generated types. Component-layer tests use Mock Service Worker (MSW) to intercept HTTP at the boundary and return canned responses.

**Tech Stack:** Vite 6.x, React 19.x, TypeScript 5.x, `vite-plugin-pwa` 0.21.x, `openapi-fetch` 0.13.x + `openapi-typescript` 7.x (consume from Spec 2's emitted `openapi.json`), Vitest 2.x + `@testing-library/react` 16.x + `jsdom` 25.x for Unit/Component tests, `msw` 2.x for HTTP stubbing.

**Reads from:** `docs/initiatives/m1-bootstrap/DESIGN.md` Decisions appendix. Honors decisions #3 (Vite + React SPA), #11 (test file locations), #12 (OpenAPI artifact path), #14 (port 5173), #15 (CORS + `VITE_API_URL`), #22 (no Integration layer in M1), #24 (pnpm script contract), #33 (MSW).

**Depends on:** DevTask 3 of Spec 2 must have merged so `components/service-task/openapi.json` can be generated. If running DevTask 6 in parallel with Spec 2 work, use hand-written stub types for the interim — but final merge must follow DevTask 3.

```ts
import { http, HttpResponse } from 'msw';
import type { Task } from '../api/client';

const baseUrl = 'http://localhost:3000';

let store: Task[] = [];

export function resetStore() {
  store = [];
}

export const handlers = [
  http.get(`${baseUrl}/tasks`, ({ request }) => {
    if (request.headers.get('x-user-id') !== 'local') {
      return new HttpResponse(null, { status: 401 });
    }
    return HttpResponse.json(store);
  }),

  http.post(`${baseUrl}/tasks`, async ({ request }) => {
    if (request.headers.get('x-user-id') !== 'local') {
      return new HttpResponse(null, { status: 401 });
    }
    const body = (await request.json()) as { title?: string };
    if (!body.title || body.title.length === 0 || body.title.length > 200) {
      return new HttpResponse(null, { status: 400 });
    }
    const task: Task = {
      id: `01940000-0000-7000-8000-${String(store.length).padStart(12, '0')}`,
      user_id: 'local',
      title: body.title,
      created_at: new Date().toISOString(),
    };
    store = [task, ...store];
    return HttpResponse.json(task, { status: 201 });
  }),
];
```

- [x] **Step 7: Implement `TaskCreateForm`**

Write `components/web_client/src/components/TaskCreateForm.tsx`:

```tsx
import { useState } from 'react';
import { apiClient, type Task } from '../api/client';

interface Props {
  onCreated: (task: Task) => void;
}

export function TaskCreateForm({ onCreated }: Props) {
  const [title, setTitle] = useState('');
  const [submitting, setSubmitting] = useState(false);

  async function handleSubmit(e: React.FormEvent) {
    e.preventDefault();
    if (!title.trim()) return;
    setSubmitting(true);
    try {
      const { data, error } = await apiClient.POST('/tasks', { body: { title: title.trim() } });
      if (error) throw new Error('Failed to create task');
      if (data) {
        onCreated(data);
        setTitle('');
      }
    } finally {
      setSubmitting(false);
    }
  }

  return (
    <form onSubmit={handleSubmit} style={{ display: 'flex', gap: '0.5rem', margin: '1rem 0' }}>
      <label htmlFor="title" style={{ display: 'none' }}>
        title
      </label>
      <input
        id="title"
        type="text"
        name="title"
        value={title}
        onChange={(e) => setTitle(e.target.value)}
        placeholder="What needs doing?"
        maxLength={200}
        style={{ flex: 1, padding: '0.5rem' }}
        aria-label="title"
      />
      <button type="submit" disabled={!title.trim() || submitting}>
        Create
      </button>
    </form>
  );
}
```

import type { Task } from '../api/client';

interface Props {
  tasks: Task[];
  loading: boolean;
  error: string | null;
}

export function TaskList({ tasks, loading, error }: Props) {
  if (loading) return <p>Loading...</p>;
  if (error) return <p role="alert">{error}</p>;
  if (tasks.length === 0) return <p>No tasks yet — create one above.</p>;
  return (
    <ul style={{ listStyle: 'none', padding: 0 }}>
      {tasks.map((task) => (
        <li key={task.id} style={{ padding: '0.5rem 0', borderBottom: '1px solid #eee' }}>
          <span>{task.title}</span>
          <time dateTime={task.created_at} style={{ float: 'right', color: '#888', fontSize: '0.85em' }}>
            {new Date(task.created_at).toLocaleString()}
          </time>
        </li>
      ))}
    </ul>
  );
}

```tsx
import { useEffect, useState } from 'react';
import { apiClient, type Task } from './api/client';
import { TaskCreateForm } from './components/TaskCreateForm';
import { TaskList } from './components/TaskList';

export default function App() {
  const [tasks, setTasks] = useState<Task[]>([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    let cancelled = false;
    (async () => {
      setLoading(true);
      const { data, error } = await apiClient.GET('/tasks');
      if (cancelled) return;
      if (error) setError('Failed to load tasks');
      else setTasks(data ?? []);
      setLoading(false);
    })();
    return () => {
      cancelled = true;
    };
  }, []);

  return (
    <main style={{ fontFamily: 'system-ui, sans-serif', padding: '2rem', maxWidth: 640, margin: '0 auto' }}>
      <h1>PSYKL</h1>
      <p>Time-independent planning. M1 bootstrap shell.</p>
      <section data-testid="task-ui-slot">
        <TaskCreateForm onCreated={(t) => setTasks((prev) => [t, ...prev])} />
        <TaskList tasks={tasks} loading={loading} error={error} />
      </section>
    </main>
  );
}
```
